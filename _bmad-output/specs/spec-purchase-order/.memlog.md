- (direction) Mode interaktif dengan jawaban baku dari user; Story Breakdown diminta eksplisit (tepat 3 story: draft, persetujuan, penerimaan); keputusan terbuka diambil opsi paling sederhana dan dicatat sebagai asumsi
- (direction) Slug purchase-order; express distill (input kaya); bahasa dokumen Indonesia
- (note) Brownfield dibaca: Product/Supplier/StockMovement model, StockMovementObserver, ProductPolicy (viewCost), StockMovementPolicy (adjust), RoleSeeder, resource Products/Suppliers/StockMovements, test AuthorizationMatrix/CostMasking/AuditTrail/StockMovement, e2e auth.setup/authorization
- (decision) Why: manager telat memesan ulang produk kritis karena PO di luar sistem; barang datang dicatat manual sebagai movement tanpa jejak ke pesanan. Tujuan: pesanan ulang tercatat, disetujui orang lain, penerimaan otomatis jadi movement tertelusur
- (capability) CAP-1 Buat draft PO dari produk kritis: manager pilih supplier, sistem menawarkan produk kritis milik supplier itu, manager isi jumlah (dan boleh ubah harga) per item, lalu mengajukan
- (capability) CAP-2 Persetujuan PO: admin menyetujui atau menolak PO berstatus diajukan dengan catatan; pembuat PO tidak boleh memutuskan PO buatannya sendiri
- (capability) CAP-3 Penerimaan barang: manager atau staff mencatat penerimaan PO disetujui; tiap item menjadi movement IN yang merujuk PO; PO menjadi diterima
- (constraint) Status: draft -> diajukan -> disetujui | ditolak; disetujui -> diterima. Tidak ada transisi lain
- (constraint) PO diterima atau ditolak tidak dapat diubah
- (constraint) Stok hanya berubah lewat StockMovement yang dibuat lewat model (Observer replay); current_stock tidak ditulis langsung
- (constraint) Harga modal di PO (harga per item, subtotal, total) tersembunyi total untuk staff, digate can('viewCost', Product::class)
- (constraint) Setiap perubahan status PO tercatat di activitylog beserta causer
- (constraint) Hak akses pola Filament Shield (Action:PurchaseOrder) + ability kustom di Policy; role admin, manager, staff; resource baru masuk RoleSeeder dan AuthorizationMatrixTest
- (constraint) Teks UI Bahasa Indonesia via ->label(), konsisten resource lain
- (constraint) Migrasi lama tidak diubah; skema baru lewat migrasi baru dengan down()
- (decision) Nomor PO otomatis PO-YYYYMM-#### berurutan per bulan (dari jawaban baku)
- (decision) Harga per item default dari harga_modal produk saat draft dibuat; manager boleh mengubah (jawaban baku)
- (decision) Satu PO = satu supplier; daftar awal hanya produk kritis supplier itu, produk tidak kritis boleh ditambahkan (jawaban baku)
- (decision) Hanya admin yang boleh menyetujui/menolak; tidak ada notifikasi (jawaban baku)
- (note) Trap: Shield intercept_gate=before membuat admin lolos semua ability Policy, jadi larangan memutuskan PO sendiri harus ditegakkan di jalur domain (seperti adjustment di Observer), bukan hanya Policy
- (note) Trap: StockMovementPolicy memberi staff Update dan manager Delete atas movement; movement dari PO bisa diubah/dihapus dan memutus jejak
- (assumption) Produk kritis = Product::withStockStatus('critical') (current_stock <= reorder_point), definisi yang sudah ada
- (assumption) Pembuat dan pengaju PO adalah manager (admin juga lewat bypass); staff tidak membuat/mengajukan PO
- (assumption) Hanya PO draft yang itemnya bisa diubah/dihapus; diajukan dan disetujui hanya bisa bertransisi; draft boleh dihapus manager

- (assumption) PO tanpa item tidak bisa diajukan
- (assumption) Nomor PO diberikan saat draft dibuat dan unik (constraint unik DB)
- (assumption) Larangan pembuat memutuskan sendiri berlaku untuk setuju dan tolak
- (assumption) Catatan wajib saat menolak, opsional saat menyetujui
- (assumption) Penerimaan selalu penuh (jumlah IN = jumlah item PO), atomik dalam satu transaksi; tidak mengubah harga_modal produk
